# About

REX/M2EX are fan-made patches for Rome: Total War and Medieval II: Total War.

They aim to bring both games into the modern era so they no longer feel dated and clunky.

## Main features

- Removed every single major engine limit like factions, regions, religions, cultures etc.
- A fully 64-bit engine, no 4GB limit, instant alt-tabbing and a new rendering backend 
- Tons of crashfixes and bugfixes
- Improved the campaign AI a lot
- Massively increased performance (~5x more FPS is not uncommon) and a few "extreme" graphics settings to make the games sparkle
- Lightning speed turn times
- A fully modern, better RTS camera with fixed zooming, middle-mouse rotation and edge panning, zoomin and zoomout uncapped by a lot
- Fully working pikemen working without sketchy fixes/removing their secondaries, fixed muskets/arquebusiers, fixed two-handers
- Compatible with all OG mods (including EOP mods)[^1]
- Scripting support, both the Lua EOP API and a new, (s)Quirrel-based API
- And many more! (the changelog has 1000+ entries by now)

[^1]: Some mods require compatibility patches due to errors in the mods making the game corrupt memory.
